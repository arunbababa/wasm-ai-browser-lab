# WASM AI Browser Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a tiny static browser demo under WSL `~/Dev/wasm-ai-browser-lab` that visibly runs an AI-like inference core through WebAssembly and can be deployed cheaply as static files.

**Architecture:** A dependency-free HTML/CSS/ES module app loads a generated WASM module that computes three small model scores. JavaScript wraps the WASM exports, normalizes inputs, ranks outputs, renders the UI, and falls back to generated bytes if the `.wasm` asset is unavailable.

**Tech Stack:** Browser ES modules, WebAssembly MVP bytecode generated by Node, `node --test`, Python static server for local preview, Cloudflare Pages or GitHub Pages for deployment.
